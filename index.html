What Is Potassium Executor?

Potassium is a premium Roblox script executor distributed through a lifetime license model. First introduced to the scripting community in March 2025, it has since become one of the most frequently updated executors available, often releasing compatibility patches within hours of Roblox updates [citation:1].

The executor is known for its high function execution capabilities, with community sources reporting 99-100% UNC and 96-100% sUNC support [citation:1][citation:4]. It includes a script hub, dark web decompiler improvements, debug features, Drawing API, and RakNet-related functionality [citation:1].

Potassium is distributed exclusively through its official Discord server. After purchasing a license and registering, users can download the executor via the psm bot using the download command with their credentials. The executor also requires login after launch [citation:1].

  6. Run and Login — Open the extracted Potassium executable and log in with your account credentials.
  7. Attach and Execute — Launch Roblox, join a game, click "Attach" in Potassium, and execute your scripts.

Frequently Asked Questions

Is Potassium Executor free?

No. Potassium requires a lifetime license purchase. It is not a free executor. Pricing is approximately $20 USD for a permanent license [citation:1].

Does Potassium work on Windows 11?

Yes, but only Windows 11 versions 24H2 and 25H2 are officially supported. Older Windows versions or modified Windows installations may encounter issues that cannot be resolved [citation:7].

What UNC does Potassium support?

Community sources report 99-100% UNC and 96-100% sUNC compatibility, placing it among the highest-tier executors available [citation:1][citation:4].

How do I fix "Could not find a part of the path" error?

This error occurs when running the executable directly from the ZIP. Extract the Potassium ZIP to a folder first, then run the executable from the extracted folder. Do not use shortcuts or Start Menu entries [citation:7].

How do I fix "Invalid Token" error?

Navigate to the Potassium folder, locate the user.bin file, delete it, and restart Potassium. This will reset your session token [citation:7].

Where can I download Potassium safely?

Only download from the official Potassium Discord server. Multiple third-party domains claim to offer Potassium downloads but are not authorized and may distribute modified or malicious files.
